# AI移動過程の描画

## 変更内容

AIがこれまで

- 置き場所を決める
- その場に一気に反映する
- hard dropする

という挙動だったものを、

- 置き場所を決める
- left / right / rotate / hold を1手ずつ実行する
- 最後に hard drop する

方式に変更しました。

## これで変わること

- AIが移動している途中の様子が見える
- `AI ops/s` が文字通り「操作量/秒」として効く
- 遠い置き場所ほど、到達に時間がかかる
- 人間に近い見た目になる
